## SQL Date and Time Functions

This section covers SQL date and time functions used to retrieve, extract, and manipulate date and time values.

### Topics Covered

* **NOW()** – Returns the current date and time.
* **CURDATE()** – Returns the current date.
* **CURTIME()** – Returns the current time.
* **DATE()** – Extracts the date from a datetime value.
* **TIME()** – Extracts the time from a datetime value.
* **YEAR()** – Extracts the year.
* **MONTH()** – Extracts the month number.
* **MONTHNAME()** – Returns the month name.
* **DAY()** – Returns the day of the month.
* **DATEDIFF()** – Calculates the difference between two dates in days.
* **DATE_ADD()** – Adds a specified time interval to a date.
* **DATE_SUB()** – Subtracts a specified time interval from a date.

### Objective

To practice SQL date and time functions for analyzing employee records, sales transactions, delivery dates, and other time-based data.
